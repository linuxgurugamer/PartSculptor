# Manual validation: soft radius slider and mirrored vertices

1. In the VAB select a symmetric cube or cylinder with compatible collision geometry. Open PG / Vertices. With mirror Off, insert a vertex, select it, enable Soft selection. Enter 0.3; verify slider tracks it. Drag slider; verify text follows; enter a radius larger than the displayed slider range and verify range expands. Enter zero and apply; verify hard selection. Invalid or negative text must not apply. Verify radius survives save/reload and undo.
2. Choose X; add a vertex on one side. Verify a second yellow handle appears at the reflected location. Undo once, both disappear. Repeat with Add edge/ring vertex. Repeat Y and Z on symmetric geometry. An insertion on the mirror plane should create just one edit.
3. Drag the selected handle using each axis arrow. For X mirroring verify X movement is opposite on the two sides, Y/Z movement equal. Repeat on Y/Z. Check previews, collision, volume and attachment nodes after release. Undo once, verify both restored. On-plane vertex should not move perpendicular to plane.
4. Ctrl-click multiple vertices including both members of a pair; verify last-selected member drives that pair once and other pairs respond appropriately. Apply equal overlapping soft radii and verify selected handles follow requested displacement. If solver is ill-conditioned, reduce radii. Delete selected; paired vertices should disappear, rings stay. Undo once. Save/reload in editor and flight.
5. Create vertices with mirror Off, then enable an axis and click Create missing mirrors. Verify counterpart creation including reflected stored displacement and radius. Verify missing/asymmetric surfaces reject the operation atomically; Off still permits unmirrored edits. Verify incompatible B9 variants are not matched and the 64-edit limit counts both sides.
6. Repeat with rotated and nonuniformly stretched parts. Mirror plane uses active native visual bounds, not current deformed geometry. Existing asymmetric offsets are not automatically equalized. Mirror UI mode is editor-only.
