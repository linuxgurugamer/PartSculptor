# PG help and radius layout

1. In the editor, open PG, switch to Vertices, add/select a vertex and enable Soft selection.
2. Verify the radius label, expanding slider and narrow numeric field appear left-to-right on one row. Drag the slider and type values such as 0.125; each control updates the other. Try 0.1234 (limited to 0.123) and 12.345 (still valid; the field can scroll). Apply and verify the saved radius.
3. Hover over Rings, Vertices, each mirror plane choice, Soft selection and Generate vertex collision fallback. Verify the descriptive tooltip appears, disappears on leaving the control and stays within the screen at the bottom edge. Scroll the Vertices panel to the fallback toggle and repeat. Verify the controls still respond normally to clicks.
4. Repeat with the alternate skin and different UI scales. Confirm the tooltip background follows the existing morph tip opacity setting.
